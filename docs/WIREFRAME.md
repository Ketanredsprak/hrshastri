## Visual system

- **Primary gradient:** `#51459D` → `#B83F81` (legacy brand, modernized layout)
- **Accent blue:** logo-aligned `#1A56DB` for secondary CTAs
- **Typography:** Plus Jakarta Sans
- **Motion:** Framer Motion on section headings, cards, hero mockup floats

## Responsive behavior

- Mobile-first stacking; hamburger nav under `lg`
- Feature grid: 1 → 2 → 3 → 4 columns
- Module sections reverse order on desktop only
